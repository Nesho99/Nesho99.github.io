# nesho.sh — terminal portfolio

A one-page portfolio that looks and behaves like a terminal. Static HTML/CSS/JS for GitHub Pages: no framework, no build step.

| File | What it is |
| --- | --- |
| `index.html` | Page shell: top bar, terminal window, command buttons |
| `style.css` | White terminal look, teal `#0B6E6E`, JetBrains Mono |
| `terminal.js` | Intro animation, commands, tab completion, history; fetches and parses `cv.md` |
| `alerts.js` | Decorative Slack-style alert feed and faded background windows (wide screens only, mutable) |
| `robots.txt` | Allows all crawlers. Also, maybe, something else |
| `cv.md` | The CV in Markdown, generated. The page reads its content from here |
| `Neven_Geci_CV.pdf` | The CV served by the `cv` command |

`cv.md` and the PDF are generated by a separate CV build, so edits made here get overwritten.

## Local preview

`fetch("cv.md")` needs a web server, so opening `index.html` straight from disk won't load the content:

```bash
npx serve .
```
